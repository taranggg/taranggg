#### How it works

When you click on a link and submit a new issue with the desired move, a GitHub Action runs a small Python script that performs the move, updates this README, and commits the changes.

Have you spotted a bug? Feel free to open an [issue](https://github.com/marcizhu/readme-chess/issues).
