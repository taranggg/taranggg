### Instructions

1. **Check whose turn it is** — the highlighted banner above the board shows **WHITE** or **BLACK**. Only play when it is your side’s turn.
2. **Pick a move** — use the [suggested moves](#suggested-moves) table below, or [play a custom move](#custom-moves) by opening an issue with your own title.
3. **Open a new issue** — click a move link (or create an issue manually). That only opens a **draft**; the game does not update yet.
4. **Submit the issue** — click **Submit new issue**. Do not change the **title** (the body can stay as-is).
5. **Wait for the bot** — a GitHub Action validates the move, replies on your issue, updates this board, and commits to the repo (usually within a minute).
6. **Pass the turn** — you cannot move twice in a row. Ask someone else to play the next move, or wait for another player.

**Tips**

- If nothing happens, you probably did not submit the issue — closing the tab without submitting does not count.
- After checkmate, stalemate, or a draw, a new game starts automatically (@taranggg can also use [ Restart game](https://github.com/taranggg/taranggg/issues/new?body=Please+do+not+change+the+title.+Just+click+%22Submit+new+issue%22.+You+don%27t+need+to+do+anything+else+%3AD&title=Chess%3A+Start+new+game) anytime).
- Pawn promotions are played as a queen automatically when you use the normal `Chess: Move … to …` title.

### Custom moves

You are not limited to the table above. To try a different (but still legal) move:

1. Go to [**New issue**](https://github.com/taranggg/taranggg/issues/new) on this repository.
2. Set the **title** exactly like: `Chess: Move D2 to D4` (from-square and to-square, letters **A–H**, ranks **1–8**).
3. Leave the body empty or use the default text — only the title matters.
4. Click **Submit new issue**.

Examples: `Chess: Move E2 to E4`, `Chess: Move G1 to F3`, `Chess: Move A7 to A8` (promotion).

If the move is illegal or the title format is wrong, the bot will comment on the issue and close it without changing the board.

To **start over**, open a new issue with title: `Chess: Start new game` (only @taranggg can restart while a game is already in progress).

### How it works

| Step | What happens                                                                                                     |
| :--- | :--------------------------------------------------------------------------------------------------------------- |
| 1    | You submit an issue whose title starts with `Chess:` (move or new game).                                         |
| 2    | The [**Chess** workflow](https://github.com/taranggg/taranggg/actions) runs on `issues: opened`.                 |
| 3    | A Python script reads the title, applies the move to `games/current.pgn`, and updates stats in `data/`.          |
| 4    | The bot posts a **comment** on your issue (success, invalid move, game over, etc.) and usually closes the issue. |
| 5    | The script regenerates the board and move table in this README and pushes a commit to the repo.                  |

The README is the live game state. Issues are only the “remote control” — one issue per move.

Found a bug? Open an [issue](https://github.com/taranggg/taranggg/issues/new) (any title is fine for bugs).
